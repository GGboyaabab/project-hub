# 项目中台

Windows 本地项目与知识工作台。最新打包文件位于 `release/1.5.0/project-hub-1.5.0.exe`。

## 本地开发

环境：Windows、Node.js 24 和 npm。在项目目录执行：

```powershell
npm ci
npm run build
npm start
```

`npm test` 运行基础测试，`npm run test:desktop` 运行 Electron 桌面回归测试，`npm run dist` 构建 Windows 便携版 EXE。`npm run dev` 启动开发模式。

仓库仅包含源码、应用图标、构建配置和测试。依赖、构建产物、本地知识导入文件、API 配置及测试报告不上传；首次运行后在应用内选择自己的项目根目录，并按需配置大模型 API。运行 `scripts/evaluate-writing.mjs` 会使用本机已保存的 API 配置并可能产生调用费用，需要主动执行。

## 猜你想问

正文及分支中的“可继续追问”“接着可以追问”会显示为最多 3 张问题卡片。点击问题后自动带入来源引用，创建当前内容下的可编辑问题草稿；点击“AI 完善分支”才请求大模型，点击“保存分支”才写入知识库并进入关系图谱。同一父级下已保存的同名问题显示“已建分支”，切换问题前会提示保留或放弃当前草稿。

新生成内容按需以“可继续追问”及每行一个问句输出，现有内容保持原始存储。没有可识别追问时，可用“自己提问”或从正文选段建立分支。当前推荐复用内容里已有的问题，不单独调用 API 生成推荐，不增加推荐请求费用。

## 关系图谱

在知识广场主区域顶部切换“关系图谱”。知识、问题、想法、解释和标签用不同颜色表示；连线来自已有分支、共享标签，以及正文中的 `[[知识标题]]`。同名知识存在歧义时不自动建立标题链接。图谱不会根据相似文字猜测关系。

拖动节点调整本次布局，拖动空白平移，滚轮或右上按钮缩放。“重置”恢复布局；点击节点预览，双击节点或点击“打开知识 / 打开分支”进入原内容。支持隐藏标签及“仅当前知识”，并沿用左侧搜索和筛选。节点位置只在当前图谱会话内保留；单次最多显示 400 个节点，超过时请缩小筛选范围。

## 知识分支

在知识广场打开笔记，选中文字后点击“从选中文字建立分支”，也可以点击段落下的“从这段建立分支”。填写问题或想法，选择“问题 / 想法 / 解释”，然后保存。

原文下的分支链接可跳到解释；分支里的“回到引用原文”可返回段落。“继续分支”允许进一步追问。删除父分支会在确认后同时删除其子分支，正文保留。原文修改后，原引用快照仍保留，可能需要手动更新引用位置。

## 大模型完善分支

打开左侧“设置 → 大模型 API”，默认地址 `https://api.deepseek.com`，模型 ID `deepseek-flash`。截至 2026-10-21，官方说明此调用名称对应 DeepSeek V4.1 Flash 1017：[官方文档](https://api-docs.deepseek.com/zh-cn/)。这是服务方别名，未来可能指向更新版本。

在应用内填写并保存自己的 API 密钥。密钥使用 Electron safeStorage 在本机加密保存，不会回传给渲染页面。更换服务地址时需重新填写密钥，避免把原服务的密钥发到新服务。兼容服务需支持非流式 Chat Completions；远程地址使用 HTTPS，本机服务可以使用 HTTP。

在分支编辑框填写“问题或标题”，点击“AI 完善分支”。当前知识标题、引用文字、问题和已有分支内容会发送给配置的服务，可能产生 API 费用。结果先进入编辑框，可修改，点击“保存分支”后才写入知识库。生成失败会保留原稿，不自动重试。AI 内容需要自行核对。

生成默认采用应用内的学习笔记写作规则（`electron/branch-writing.mjs`）：问题先给答案再讲原理，想法补充可行路径与最小验证方法，解释讲清机制、符号及具体例子。共同要求保留原意，区分引用、补充解释和假设，不编造来源，减少套话，并按需要提出可继续追问的问题。规则在单次 API 请求中生效，不增加额外的润色调用，也不会自动重写已有笔记。模型没有联网检索工具；这些要求不能替代事实核查。

2026-10-21 已使用保存的 DeepSeek 配置完成三类分支生成及一次定向复测。依据结果补强了实验测量的写作规则，生成内容仍需审校。实际调用记录保留在本机的 `test-results/`，不随源码上传。

数据保存在 Windows 用户应用数据目录下的“项目中台”文件夹，替换 EXE 不会迁移或清空笔记。真实服务需用户提供有效密钥，测试使用本地模拟 API，不消耗用户额度。
